# 删除生命周期移除说明

按当前范围，整体移除 DeletionRequest 和 DeletionTombstone，包括冷静期、申请/取消、后台任务、重试、匿名化、完成邮件和独立台账重放。账号与团队删除不再作为当前模板功能。

删除申请及后台页面退役；`DELETE /users` 同样关闭，不回退到立即硬删除。注册、登录、资料修改、团队成员管理和账号/团队暂停恢复仍保留。

历史前向迁移删除模块表、旧任务和专属通知。历史迁移现已合并为 [初始化迁移](../db/migrate/20261118190000_init_data.rb)，新数据库不创建这些模块表；已有数据库须先使用合并前的版本迁移至 `20261118190000`，再切换到合并后的版本。执行历史清理时，旧 worker 必须先停止，运行中的删除任务会阻止迁移。待删除团队保守转为暂停；已进入不可逆阶段的账号或团队保持不可访问，已有 deleted_at/deleted 标记不清空。

本轮不继续执行历史删除申请，也不删除磁盘上的旧台账文件。迁移不可逆，有历史数据时应先备份；开发和生产数据库不在本轮自动迁移。
